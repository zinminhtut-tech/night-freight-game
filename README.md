# Night Freight: the game

The finished, playable Windows build of **Night Freight**, a 2D action
side-scroller set aboard a Japanese ghost train running through the night.
Cross seven carriages of dark wood and warm lantern light, from the
locomotive to the shrine car, and reach the end of the train.

## How to play

1. Download **both** files: `NightFreight.exe` and `NightFreight.pck`
2. Keep them together in the same folder (the game will not start without
   the .pck file beside the .exe)
3. Run `NightFreight.exe`

No installation needed. Windows may show a SmartScreen prompt for an
unsigned program; choose "More info" then "Run anyway".

## Controls

- Run, jump and **double jump**, dash, and attack (left mouse click)
- Benches are checkpoints: death returns you to the last bench you rested at
- Resting at a bench restores you, and resets the train's enemies
- Levers open the way between cars
